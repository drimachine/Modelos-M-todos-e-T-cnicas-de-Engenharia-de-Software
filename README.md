# Módulo de Pedidos e Entregas

## Objetivo

Este repositório tem como objetivo documentar a estrutura e o planejamento do projeto **Módulo de Pedidos e Entregas**, incluindo sua Estrutura Analítica do Projeto (EAP), organizada em entregas e níveis hierárquicos.

O projeto contempla os requisitos, o projeto do sistema, a construção das funcionalidades e a preparação para a entrega.

## Estrutura do repositório

- `README.md`: apresentação e objetivo do projeto.
- `EAP.md`: Estrutura Analítica do Projeto, organizada em três níveis.

## Etapas do projeto

1. **Requisitos:** lista de requisitos priorizada e histórias de usuário.
2. **Projeto:** diagrama de classes e protótipo navegável.
3. **Construção:** API de pedidos e telas do aplicativo.
4. **Entrega:** plano de testes aprovado e pacote de implantação.
